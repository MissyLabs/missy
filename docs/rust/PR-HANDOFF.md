target-host access, live migration or process cutover is part of this work.

### Boundaries

This is the source conversion, not a claim that Robby's host or accounts have
been exercised. Real provider/Discord credentials, actual GPU models/hardware,
deployed infrastructure and live quality remain operator acceptance. Typed,
reviewed capabilities deliberately replace unsafe arbitrary execution, implicit
cross-principal recall, reaction approvals and ambient credential discovery.
Read the matrix for API changes; old Python config/vault/checkpoints are not
silently trusted or replayed.
